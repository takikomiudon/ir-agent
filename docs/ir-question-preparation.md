# 著者のDD手順からIR質問を準備する

Anthropicの固定版[dd-meeting-prep](../third_party/anthropic/skills/dd-meeting-prep/SKILL.md)を、目的・既知情報・懸念から優先質問を作り、資料間の比較とfollow-upへ結ぶ手順として参照する。[取得・licenseの証跡](../research/ir-author-management-meeting-skill-2026-10-15/README.md)を保持する。元資料はPE面談用で、以下は公開IRへの本プロジェクトの適応である。

| 原文の手順 | 公開IRで記録する内容 |
|---|---|
| 目的・既知情報・懸念 | 会社、公式窓口と受付条件、既存仮説/論点、確認したい定義、既読資料。既存草案があれば参照する。 |
| 優先順位とtopic別の質問 | 確認によって変わる前提と、問う理由。不明というだけで優先質問にしない。 |
| 比較値・資料間の不一致 | 原値、作者、期間、対象範囲、原文位置。定義の違いを矛盾と決めず、未確認の業界平均を補わない。 |
| 非誘導の問いと具体確認 | 公開説明の対象範囲を中立に確認する。「一時的ですよね」など期待する結論へ誘導しない。 |
| follow-up | 追加で必要な公開資料と該当箇所、残る条件。新しい資料や返信がないまま同じ確認を繰り返さない。 |

原文の1頁準備票に沿って整理するが、正式質問の登録・送信準備完了とは扱わない。原文に回答分岐・無回答処理・EPS/CF更新・売買価格の規則はない。仮説、変更可能な入力、回答別の分岐は[既存の質問前契約](workflow.md#質問前の方針固定と判断履歴)で固定する。比較値の存在も公正倍率の採用とは別である。

公開Q&Aの具体的な読み分けは[読解の手順](public-qa-reading.md)を使う。質問者の前提を会社の認証済み数値へ移さず、当時業績予想と将来中計、採用flowと人員stockの違いを揃えてから比較する。既答を再質問から除き、残る定義がどの比較/既存入力を変えるかに絞る。

数値仮説が未完成でも、定義回答によって比較方法が変わる問いは[研究inquiry](research-inquiries.md)へ事前保存できる。既存case版・公表原典と、A/B・混合・未解決の比較注記を固定する。返信原文・公開性のレビュー・現在の利用可否を分け、金融入力の変更が必要になった場合は別途既存の金融契約を使う。

[5988の減損/CFO対応](../research/ir-case-studies-2026-10-15/5988/cashflow-oneoff-bridge-review.md)と[税効果注記](../research/ir-case-studies-2026-10-15/5988/tax-basis-review/tax-basis-review.md)のように公開資料で解けた過去の区分を、原文に一時費用の質問例があるという理由で再質問しない。残るcash範囲・将来税/NOLも、判断価値や採用入力がなければ質問優先を確定しない。

公開資料の確認範囲・時点・引用は、任意の [`question.public_information_review`](workflow.md#出典付き方針で判断を点検する) として不変質問へ固定できる。読んだ資料のID/native JSON SHA、頁・表・対象期のscope、逐語quoteと、残る問いの理由を保存し、実保存来歴と現在の公開性訂正も別に照合する。これは本プロジェクトの参照固定であり、未回答の意味・実読・全資料の最新性や送信準備完了の認証ではない。レビュー根拠を評価入力へ自動採用せず、未導入の旧経路・外部既送信記録は区別する。

PEのCIM/data roomや非公開顧客情報の要求、第三者への連絡、買収手続き、身振り・自信の評価は採用しない。会議向けの15–20問・60–90分をメール/フォームの数値条件へ移さず、公式受付条件を確認する。原文の外部操作は実行しない。

## 日本IR協議会の企業向け指針を準備へ適応する

日本IR協議会が2018年2月28日に公表した「情報開示と対話のベストプラクティスに向けての行動指針」を、質問対象の整理と公開資料への照合の設計参照にする。[保存済みレビュー](../research/ir-jira-dialogue-best-practices-2026-10-15/README.md)は全34頁のうち物理/印字9・14・25頁を本文・画像で確認した範囲であり、残り31頁や後年の変更を意味読解済みとはしない。

| 指針が企業側へ勧める実務と頁 | 本プロジェクトの投資家側への適応 |
|---|---|
| FDの目的を理解した対話と、資料・共有に適する回答/FAQ・要点の公開（9・14頁） | 対話前に既公表資料・FAQ・会社方針を照合し、既答部分を草案から除き、残る対象期/範囲を明示する。 |
| 公表済み過去実績の変動要因・予想と異なった理由、戦略の方向感・考え方・前提の説明（25頁） | 公表値と期・作者を示して意味や要因を問う候補にする。未公表の進捗数値や目標達成保証を求める理由にしない。 |
| 有益な要点/FAQの公開と回答方針の一貫性（14・25頁） | 公表箇所の案内を受けられる形を用意し、案内資料や後日公開の版・期・対象系列を元の問いへ照合する。 |

これは上場企業側の望ましい実務を示す当時の指針で、投資家に必須の質問順序、現在の法令判断、個人への返答保証を定めるものではない。対話前の公開確認と対話後の照合は本プロジェクトの適応であり、個別3社の質問や回答分岐を同協議会の作成としない。

9・25頁の情報取扱いに関する留保も残す。指針のモザイク情報の説明だけで個別返信を `public_clarification` へ自動分類せず、受信原文と公表根拠を点検する。`unclear` / `potential_nonpublic` の利用保留、固定済み回答分岐、数値入力の出典・範囲・採用確認は維持する。この接続で質問・回答分岐・金融方針・株価条件・IR確率を追加せず、既存草案の正式登録/送信準備完了とも扱わない。[適用記録](../research/ir-jira-question-method-adoption-2026-10-15/manifest.json)に原典と変更範囲を保存する。


## 後続公表で、問いの前提を更新する

Anthropic earnings-previewの予想の出典・日付を追う手順を使い、質問前に同じ年度の利益額、EPS、株式数の基準と注記を比較する。EPSの増減だけから利益見通しの変更を判断せず、「業績予想修正なし」という表示だけで全表示値が同じとも決めない。

[4318のQ1短信の確認](../research/ir-case-studies-2026-10-15/4318/subsequent-Q1-public-review-2026-10-16/parent-acceptance.json)では、2026年7月31日時点の通期親会社利益予想2,805百万円は4月30日と同額だった。一方、予想EPSは50.00円から50.27円へ変わり、自己株式の取得と報酬としての自己株式処分を考慮したとの注記がある。この公表済みの説明を既知情報にし、利益予想の上方修正と読み替えて質問や分岐を作らない。年次実績EPS74.11円、Q1実績36.77円、通期予想50.27円は別の対象期・種類で保持する。

同じ短信は四半期財務諸表の金額単位を千円から百万円へ変更し、比較期も百万円へ表示し直している。元の年次PLと比較するときは金額単位を揃え、株数や1株当たりの円銭はそれぞれの単位のまま扱う。これは出典付き予想・期間・指標定義を追う既存の研究手順への適用例である。
