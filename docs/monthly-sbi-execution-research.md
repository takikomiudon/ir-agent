# 月1万円・SBI証券での実行条件

利用者の条件は、月1万円の積立、SBI証券の継続利用を想定、特定スタイルの希望はなく公開ルールとの適合を優先すること。[回答の記録](../research/ir-user-operating-constraints-2026-10-16/constraints-v2.json)を保持する。月額は現在残高・初期資金・1社あたりの配分とは異なる。

SBI公式の[紹介ページ](../research/ir-SBI-S-stock-sitemap-followup-2026-10-16/parent-acceptance.json)、[サービス概要](../research/ir-SBI-S-stock-service-overview-2026-10-16/parent-acceptance.json)、[手数料の限定確認](../research/ir-SBI-S-stock-fee-meaning-review-2026-10-16/parent-acceptance.json)を使う。2026年10月16日に取得した静的説明で、利用者の口座画面や個別銘柄の取扱状況を照合した記録ではない。

| 確認項目 | 公表説明 | 研究上の扱い |
|---|---|---|
| 購入単位 | 紹介に1株から、注文手順に1〜99株。 | 100株分を直ちに買えないことだけで企業を除外しない。 |
| 市場 | 東証プライム・スタンダード・グロースは買付/売却。名証・福証・札証は売却のみ。 | 新規買付の経路を区別する。市場名だけで個別銘柄のS株対応を認証しない。 |
| 対象銘柄 | 個別銘柄画面の取扱情報で確認する旨。 | 公開市場区分との結合は研究候補の作成まで。現在の取扱確認を別に残す。 |
| 費用 | サービス概要には買付・売却手数料無料、スプレッド無しの明記。 | ネットコース・ネット取引という手数料詳細の範囲と併読する。全費用ゼロや本人への適用とはしない。 |
| 口座 | 特定・一般・NISA。NISA買付は成長投資枠のみ。 | 既存の積立がどの口座/制度かは不明。つみたて投資枠と混ぜない。 |
| 自動買付 | 紹介に日株積立によるS株対象銘柄の自動買付。関連サービスに1,000円からとの説明。 | 手動S株の最低単位と自動積立の設定額を分ける。口座設定や積立設定は行っていない。 |
| 約定 | 注文時間帯によって前場始値・後場始値・後場終値・翌営業日前場始値。 | 判断時の表示株価で即約定する前提を置かない。 |
| 買付余力 | 翌日の制限値幅上限による余力再計算で失効する場合がある。 | 表示株価が月額以下でも注文受付・約定可能とは断定しない。 |
| 未約定 | 後場に繰り越した後の失効、大引けストップ配分では配分なし等。 | 判断候補・注文・実約定を別に記録する。 |
| 単元到達 | 合計が単元株数以上になると単元分は通常単元で売却し、到達当日は単元分を売却できない旨。 | 保有株数や購入履歴を無視して退出可能数を決めない。 |

詳細の時間帯、締切直後の処理例外、注文訂正不可と取消/再発注、発注回数の記述はサービス原文へ戻って確認する。受付時刻の表示だけから取引日・祝日・UTC時刻・注文可否を自動計算しない。注文回数の一般文と、発注タイミングごとの買/売各1件という説明を一方だけで要約しない。

## 既存の投資ルールとの接続

[Acquirer’s Multipleの原典手順](acquirers-multiple-research.md)には最低20保有の分散ガイドと段階購入の提案がある。S株で購入単位が緩むことは、そのまま20銘柄を保有できる証明ではない。残高・銘柄別の必要資金・配分・既存保有・対象銘柄の取扱いと、著者の保有/売却条件を別に照合する。金額に合わせて分散数や退出条件を独自に変更しない。

候補の市場区分、会計データの比較可能性、著者の選別条件、IRで減らす不確実性、回答後に再検証する入力、価格条件、実行条件の順で不足を分ける。会社へのIRで、証券会社の注文条件や著者の順位・公正価値を確定させない。約定や資金に関する不足を企業側への質問へ押し出さない。

この文書は公表説明と利用者条件を結ぶ研究手順。新しい利確率・損切り率・均等配分・企業の買い順位・自動注文を追加するものではない。
