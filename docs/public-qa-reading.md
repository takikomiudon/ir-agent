# 公開Q&Aを既知情報と残余へ分ける

公開Q&Aでは、質問の前提と会社が実際に答えた範囲を分けて読む。Anthropic DDの既知情報・margin bridge・資料差の明確化・非誘導と、日本IR協議会の公表実績の変動理由・公開回答に関する企業向け推奨を、公開Q&Aへ適応した本プロジェクトの手順である。外部著者が定めた投資規則ではない。

1. 原source・引用位置・話者と、対象期・実績/当時予想/目標を対応づける。元の問答と必要な前後文を読み、質問者の「〜ではないか」「〜のようだ」を会社の認証済み事実に移さない。回答が前提を明確に確認したか、別の理由を答えたかを区別する。編集・加筆されたQ&Aはその注記を保持し、逐語録と扱わない。
2. 異なる回答を比べる前に、指標・期・組織/事業範囲・計画版を揃える。当時業績予想と将来中計、採用人数というflowと人員数というstockを同じ条件とせず、違いだけで矛盾・反証にしない。未確認の退職・配置転換・平均人員を逆算しない。
3. 会社の変動理由や主な費目の説明は、その回答が対象とする期と範囲で既答にする。主な項目・概数の列挙を完全な増減表、税後親会社利益や正常EPSまでの調整表と扱わず、合計/残差を補わない。部分的な理由説明にも定性比較の価値はあり、価格・正常EPSの未完成だけで研究を止めない。
4. 文書日・会合日・掲載日・取得完了・実DB初保存を分ける。URL名やHTTP更新日時から公表日/精密時刻を作らず、時刻があっても明示されないtimezoneを補わない。古いQ&Aの会社見通しを、後続決算や現在の予想維持にしない。
5. 既答部分は再質問から除き、未読の公開回答候補、会社が確認できる定義、著者/投資家が決める将来予測・価値を分ける。残る確認がどの比較や既存入力の意味を変えるかを示し、案内された公表資料は版・期・対象系列へ照合する。曖昧・回答対象外は未解決であり、売買や会社仮説の否定へ自動変換しない。
