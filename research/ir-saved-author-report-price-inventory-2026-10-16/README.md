# 保存済み著者レポートの株価参照

**新GETなしで、コード・明示円・観測日・実株価が揃う過去参照を2件確認した。** 新しい価格providerがなくても日付付き研究参照は一部存在する。ただし、10月16日の現在価格や金融判断に使える鮮度を確認した結果ではない。

調査はこの5社だけで終了。既存7年次Graham cohortと今回の固定群の重なりは1518のみで、残る6社の保存report有無まで調べたとはしない。価格発見は投資候補・監視・モデルroute・株価優先順位の変更ではない。目標株価・配当・時価総額から価格を逆算していない。

[quotes.json](quotes.json)は2候補と2983の最小exact引用5件を保存本文のUnicode／UTF8半開offsetへ照合し、6323の画像転記1件を別区分にした。[inventory.json](inventory.json)はsource object保存file、native JSON SHAとcontent SHA、原URL、保存時刻、未確定を分ける。保存source objectと本文の完全一致を確認したが、実DBへ接続してID・first-save・現在利用可否を確認してはいない。

日精度は既存quoteの情報形に対応する候補で、秒精度や実引け時刻を補わない。既存normalize_jquants_quoteはJ-Quants専用なので著者の散文を投入しない。この票だけで既存price_path／observed_at_pathを満たしたとも扱わず、まず日付付き研究参照としての用途を選ぶ。現sourceの変更、新source／adapter／DB登録は不要な本段階では行わない。

過去の株価に観測日後の年次実績・会社予想・著者予測を組み合わせると先読みが生じ得る。保存日は10月15日であり価格観測日に本システムが知っていたとの主張はしない。allow_date_precision・許容鮮度・データreuseの許諾を新たに採用せず、現金融入力へ自動流用しない。

全13根拠pinと5exact引用を再照合した。新GET・DB接続・キー参照・旧file／コード編集・価格算術・新source／quote生成は0。固定群の候補存在確認だけを完了して停止する。
