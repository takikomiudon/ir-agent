# 1,819社の評価モデル点検へ進むための母集団

実DBの窓口候補1,819社を、固定した全社CSV3,686社へ証券コードで照合した。[全件CSV](all-1819-model-intake.csv)に、元の業種・市場、DB会社snapshotのSHA、保存済み公開/財務資料数、未確認状態を保存した。全コードが結び付き、会社/窓口/保有/状態は変更していない。

銀行10・証券商品先物18・保険8・その他金融20の計56社は、会社原本で金融構造を先に確認する手掛かりになる。[56件の確認task](financial-structure-evidence-tasks.json)は金融仲介・資金負債・規制資本を調べる依頼で、専用modelへの自動割当ではない。56社はいずれも現行研究DBの公開財務sourceがまだない。残り1,763社も通常modelに適合済みとはせず、循環・赤字・資金調達等の会社根拠が未確認のまま残す。

根拠は採用済み[Damodaranの研究振り分け](../valuation-model-routing-2026-10-15/routing.json)。業種名だけで除外せず、銀行のPERも一律禁止しない。今回の4業種labelは仕事を分けるプロジェクトの手掛かりであり、著者が同じlabel表や投資順位を指定した意味ではない。会社ごとの事業・資本・期間を確かめてからモデルを点検する。

IIJ3774・パイオラックス5988のDB名には「株式会社」があり、元CSVは短い上場会社名だった。コード一致と両表記を保持し、社名を黙って修正していない。56社の金融手掛かりでは名称も完全一致した。

[validation](validation.json)に元CSV/方針/出力のSHA、業種別件数、全照合、名称差、read-only DBの前後SHAを保存した。時点は2026年10月15日の現在DBと、10月13日版の窓口調査CSVであり、全社の当日上場・現在のIR受付や投資適格性を再確認した結果ではない。新GET・code実装・DB書込み・除外・モデル採用・IR・注文は0。
