# 会社公表値をFCFE中間計算へ対応付ける

会社1Q短信p1の通期NI予想115,000百万円（2026年4月〜2027年3月）を、[NI入力の候補](input-map.json)として引用・画像・元source SHAへ結び付けた。会社予想を実績・外部独自予測・当日最新へ変えず、親会社株主利益と意図する株主範囲の整合も未確認として残す。既に確認したp1を再利用し、新しい意味読取頁は0。

同じ年間の規制資本再投資は未確認である。足元のQ1純利益、資本残高差、規制比率16.24%、所要資本計算の8%を代入しない。このmapは実行可能なcalculator入力ではなく、実企業のFCFEは計算していない。

著者式の下では、NI・期間・株主範囲が同じなら、根拠付き再投資額が増える分だけFCFE中間量は減る。IRで資本政策の定義を確認する意味はこの対応にあるが、現時点では再投資額・完全な資本目標/分配政策・金融判断への影響は未確認。会社に投資家の評価や退出条件を保証させない。質問前に保存済み公式プレゼンの明示リンクから公表方針を確認する。

[validation](validation.json)で旧sourceの同頁引用・画像・SHAと未設定値の保持を点検した。独立した意味レビューは未完了。新GET・意味頁・DB書込み・実質問・送信・注文は0。
