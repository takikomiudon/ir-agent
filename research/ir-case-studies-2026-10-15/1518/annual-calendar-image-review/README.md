# 1518 — 年間スケジュール図の限定目視確認

保存カレンダーの実 img src から JPEG を1 GET（200）し、保存原画像を `view_image` の original で確認した。770×190、SHA は review/validation に保存。

図は「4月」から「3月」の年次パターンで、「決算発表」「配当金支払」「株主総会」の3行。決算ラベルは期末・第1・第2・第3四半期で、配置は概ね5・8・11・2月付近。具体年・具体日・沈黙期間表示は図内で確認できない。ラベルが月列をまたぐため、配当・総会は文字を保持し厳密な単月対応は未確定とした。正確な次回予定日を登録する根拠にはしない。

隣接する「2026年度（第171）期」は別の開示一覧見出しで、画像の年度へ補完していない。HTTP Last-Modified やテーマ名も図の適用年度にしない。沈黙表示が図内にないことから会社の沈黙期間不存在を認定しない。

[review.json](review.json) は手動転記と限界、[validation.json](validation.json) は原バイト・JPEG・旧入力不変の照合。前phaseを変更せず、DB・質問・送信・モデル採用は0。研究管理日や売却期限とも別である。
