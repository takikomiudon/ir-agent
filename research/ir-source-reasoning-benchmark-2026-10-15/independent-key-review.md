# 固定8例の独立キー点検

入力・キー・manifest・protocol・validationの5ファイルと、それらが指定する保存原典だけを読んだ。trial回答・executionは読んでいない。これはキーを読んだ担当者による監査で、fresh blind trialの回答や採点ではない。元5ファイル/キー/原典は変更0、GET/DB/コード/追加case/金融採用/送信も0。

8例のキーに明確な修正理由は見つからなかった。これは判定者間の信頼性やモデルの全成功を認定した結果ではない。

| Case | 固定キーについての点検 |
| --- | --- |
| B01 | not_establishedが妥当。拠点遅延だけでは、継続顧客比率の頭打ちも含む引用の条件全体を確認できない。ANDを必要十分条件に強化したり、実際の減速自体を否定したりしない |
| B02 | supportedが妥当。期間/百万円/当期列と特別損失423・営業CF正の調整423の二つの表示が揃う。新規現金流入や正常利益採用は含めない |
| B03 | not_establishedが妥当。CF調整から営業利益加算・正常利益採用を導く規則は抜粋にない。外部会計知識や抜粋にない営業利益行で判定を置き換えず、明示禁止文も作らない |
| B04 | supportedが妥当。2027年3月期通期連結の同EPS列で前回185.40・修正229.67という版の対応を確認できる。実績や現在の予想とはしない |
| B05 | not_establishedが妥当。「予定」は実際の完了証明ではなく、未実施の証明でもない |
| B06 | not_establishedが妥当。会社目標40%と著者の伸び悩み注視を同じ反証閾値とする記述はない。閾値の一般不存在も主張しない |
| B07 | supportedが妥当。単位・年度列・NI行は原HTMLの同一table内。2027計画378億円の表示単位算術は37,800百万円。非丸め値や予想採用へ広げない |
| B08 | contradictedが妥当。「会社予想純利益をベースに当研究所で算出」は、会社利益を使わない独自純利益予測という主張と両立しない |

原典8資料のraw/text/参照record SHA、12抜粋の保存表現と文字offset/UTF-8 SHA、PDF該当抜粋のform-feedによる物理頁と頁内offset、先行引用参照、著者手順3引用を照合した。原文CRLFは変換していない。印刷頁番号の画像再読取やPDFからの再抽出は今回行っていない。

E02は先行OC05の完全コピーではなく、E03/OC05と同じ保存PDF頁の表頭を追加したもの。manifestはその由来を明記し、追加部分の原文offsetも一致した。S02のsource_recordは原bundleではなく先行reviewで、そのinventoryのsource ID/raw/textへの対応を確認した。元source snapshotそのものや当時のDB可用性を独立証明したとはしない。

入力にキー・期待分布・既存解釈ファイルへのpath・具体的な正答付き回答例は見当たらない。ラベル定義とplaceholderは正当なtask契約である。ただし手作業の主張文の語調がラベルの手掛かりになり得ること、B02/B03が同じ抜粋を共有すること、既知研究から選んだ8例であることは残る。直接の答え漏れがないことを、holdoutや汎化・訓練データ非重複の確認へ拡張しない。

[JSONレビュー](independent-key-review.json)に固定ファイル5件のSHA、原典30ファイル不変、個別照合と限界を保存した。親が伝えた11:39:51のfreeze時刻は別ファイルを読まず申告として区別し、現在のキー/入力/手順ハッシュの結合は独立照合した。trial結果によるキーの調整は行っていない。
