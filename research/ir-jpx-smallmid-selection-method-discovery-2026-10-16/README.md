# JPX日経中小型株指数の選別方法：有限の原典確認

実績に基づく候補選別の原典を取得できた。東証の対象母集団から適格性・規模・流動性で絞り、3年平均ROEと3年累積営業利益の順位点を70%／30%で合成し、定性加点・低収益銘柄の後順位化・既存構成の維持条件を経て原則200銘柄を選ぶ。今回読んだ選定節には会社EPS予想や外部目標価格を必要とする条件はない。

公式算出要領は2026年8月3日版・同日発行、22頁。全文を保存し、目次で所在を確認した後、**物理11–14頁（印刷10–13頁）のみ**を本文・画像で意味確認した。版の表示日、各規則の施行日、2026年10月16日の取得時刻を区別する。各規則の要約・節番号と短い逐語引用のoffsetは [review.json](review.json) と [quotes.json](quotes.json) にある。

大型株除外の既存構成向け境界が、公式HTML概要では上位18%以内、PDFでは14%以内と異なる。どちらが現在実施されたか、差の原因や施行時点は決めない。詳細財務データ定義（保存PDFの未読III.4）、定性加点の具体点数、裁量・外部データ等も残るため、完全自動再現可能とは認定していない。343社だけで全市場の百分位・中央値を計算して指数ルールと呼ぶこともできない。

定期入替は6月最終営業日基準、8月第5営業日公表、8月最終営業日から入替後算出。非定期除外と企業再編等の特別追加も規定される。これは指数の運営日程であり、既存の四半期点検、利用者の数カ月〜1年の保有期間、個別株の売買注文・利確条件とは別である。指数採用は公正価値や買い推奨を与えず、除外基準も全社の投資不適格判定に置き換えない。
