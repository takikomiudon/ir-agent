# 方針固定とIR判断の統合チェックポイント

2026-10-15の継続作業の途中成果。作業終了を表すものではない。

- 質問前に方針版・仮説・回答分岐・許可した入力差分・価格根拠を固定する。
- 公開性を確認した返信だけモデルへ反映し、保存された価格とその時点で既知の保有状態で判断する。履歴不明は保留。
- 返信の分岐案 `precommitted_action` と価格条件付きの `action` を分け、方針未固定の旧案件は価格判断を未解決とする。
- 公開性の訂正を追記し、古い判断は現在の表示で保留する。新しい訂正版を実際に参照したか版を照合し、後から保存した過去時点の判断が現在判断へ復活することを防ぐ。
- EVSIは著者の定義に従い、IRを不完全な信号として明示入力から計算する。観測頻度を将来尤度へ自動変換しない。

[操作手順](../../docs/workflow.md)、[13段階の運用設計](../../docs/ir-operation-design.md)、[採用元](../../docs/decision-policy.md)を参照する。原本・過去履歴は変更していない。

この時点の全789テストは成功（33.797秒）。[テストログ](tests.log)と[架空の一連の例](synthetic-policy-workflow.json)を保存した。架空例では分岐案がbuy_reviewでも、株価が目標に達しているためexit_reviewとなる。架空の数値は実運用方針ではない。

実台帳は窓口1,819社、全社watch・非保有。2社の公開資料20件を元取得時刻・原本hash・抽出範囲付きで取り込んだ。財務指標・将来利益・市場価格・仮説・数値方針は未採用。[不足資料の全社一覧](coverage.json)に、保存資料の分類2社、財務資料の取得1,817社などの次タスクを記録した。窓口があることや資料取得を投資適格性と混同しない。

実IR送信・フォーム投稿・注文・有料契約・常駐スケジューラ設定は行っていない。観測設計の不変保存と後続結果の版管理は、このチェックポイント後の作業として進行中。
