# 単一DCF評価額と価格比較に明示購入規則があるか

本範囲では、**採用できる明示購入規則は未確認（候補0件）**。価値と価格の比較までを確認した。現在の確率加重期待上昇余地を、著者の唯一の方法とは帰属できないが、代わりのbuy条件も原典なしには作れない。

| 読取箇所 | 確認したこと | 確認していないこと |
|---|---|---|
| Damodaran *Ups and Downs*（2009年9月）p18 | 即時正常化で4,735円。2009年初めの3,060円に対し “significantly undervalued” [VP01] | 具体的な購入・売却指示、許容割安幅、本人費用 |
| 同p25 | 段階的正常化で3,943円。2009年2月の3,060円より “significantly higher” [VP02–03] | 差から逆算した20%等の閾値、現在のToyota予測 |
| 同p25の一般的シナリオ手順 | 期待値には確率評価が必要。一方 “or the range in values … to make our investment judgments” と選択肢を示す [VP04] | 範囲の大小から購入を決める操作可能な規則、Toyotaの3シナリオ/確率 |
| *Introduction to Valuation, Spring 2025* slide6 | 価値と価格の非効率が “how and when” 修正するかという仮定も必要 [VP05] | 数カ月〜1年以内に価格差が修正する保証 |
| *Valuation Project, Spring 2025* slide8 | 評価法の整合を検討した上でbuy/sell/holdの推薦を要求 [VP06–07] | 単一DCFと価格を比較した後の明示購入閾値/自動規則 |

p18/p25は異なる正常化仮定の比較で、段階的DCFの予測3年を3シナリオとは扱わない。各値の確率はこの2頁では未確認であり、単一値へ確率1を置かない。課題文のDCF・相対・オプションも評価法3種類であり、強気・基本・弱気の3ケースとは別である。

原著の方法の幅と現行コードの契約は区別する。[判断方針](../../docs/decision-policy.md)は、新規購入の期待上昇余地を確率なしでは算定しないというプロジェクト契約を明記している。本読取はそのgateを外す根拠でも、別policyを採用する作業でもない。購入許容差・費用・リスク・触媒/時期を勝手に補わず、IR回答から価値が変わっても買い条件へ直結させない。

著者表示3,943円と、既存の[表示入力再現の独立記録](../ir-toyota-author-valuation-readiness-2026-10-15/independent-review.json)の約3,944.09円との差は残す。本タスクで未表示精度を逆生成せず、当時の価格を現在価格として使わない。

引用の原文・頁内/全文offset・保存原典path/SHAは [review.json](review.json)、原典4箇所の局所再抽出と旧入力の不変確認は [validation.json](validation.json)。Toyotaは物理p18/p25だけ、既読valuation原典はslide6/slide8の計2箇所だけを再読した。資料全文や別資料の探索は行っていないため、他箇所にも規則がないとは主張しない。GET・DB・コード/旧成果変更・金融採用・新価格/予測・IRは0。
