# 日本株のメール・フォームIR窓口調査

確認日：2026年10月11日（日本時間）。想定保有期間は数カ月〜1年。

**49社を調べ、37社で公式のIR窓口案内を確認した。このうち返信を使う調査の窓口候補は35社。メールまたは入力項目まで確認できた候補が29社、公式案内・リンクの確認に留まる候補が6社。** 個別返信なし・受付対象の制限で別枠とした会社は2社、IR用メール／フォームが未確認の会社は12社。

これは問い合わせ経路の調査で、投資推奨や買付対象の確定ではない。個別業績・現在株価・流動性・値幅・イベント日程はまだ調べていない。受付案内やフォームの存在を、実際の回答実績・返信保証・メール到達・送信成功と同一視しない。外部への問い合わせは一件も送っていない。

## 何を確認したか

公式IRサイトから連絡先へたどり、IR専用フォーム、IRカテゴリ付きフォーム、明記されたIRメールを採用した。製品・採用・広報用の一般窓口だけではIR受付と判断していない。外部フォームは公式ページからのリンク／埋め込みを確認した。HTTP 200だけ、空本文、JavaScript読み込み画面だけでは入力項目確認にしない。個人受付は、個人投資家の選択肢や記入方法の明記がある場合に限って「明示あり」とした。

「公式案内・リンク確認」は、IR受付の説明や公式リンクはあるがフォームの実項目までは確認していないもの。リンク先のアクセス失敗・JavaScript描画等の理由は各社の注意点に残した。個人条件の明示未確認は、個人不可でも無条件受付でもない。

上場照合には[JPXの東証上場銘柄一覧](https://www.jpx.co.jp/markets/statistics-equities/misc/01.html)（2026年9月末、10月5日更新）を使った。取得した全4447レコードのうち内国普通株は3702銘柄で、掲載会社は全てこの普通株一覧と一致した。[現行の上場廃止・予定一覧](https://www.jpx.co.jp/listing/stocks/delisted/index.html)（10月9日更新）もコードで照合し、掲載会社の一致はなかった。9月末以降の全企業変更や投資時点の取引可否を保証する照合ではない。全銘柄のIR窓口を網羅調査したものでもない。

原ギフティ4449は上場廃止一覧に2026年6月29日で掲載されている。現行公式株式情報とJPX一覧に一致する **ギフティグループ590A** へ訂正した。旧コードをそのまま監視対象にしていない。

以前の業界選別に沿って、IT／業務ソフト・機械／電機／部材・消費／サービスを中心に候補を選んだ。銀行・保険、REIT、ETF、商業化前の二択事象が価値を支配する事業、専用の市況モデルが必要な資源・外航海運等を今回の探索の中心にしていない。業種名や低い値動きだけでの機械的な投資除外は行っていない。

## ハーネスへ取り込む場合

公開窓口の確認を、投資候補の選別完了として登録しない。以下はwatchの会社と窓口証拠のみを取り込み、activeの仮説を作らない。窓口資料にはrequires_research=falseを設定している。既存DBの会社のstatusやheldは、既存ハーネスの取り込み規則で保持される。

```bash
.venv/bin/ir-agent --db data/research.sqlite3 ingest research/ir-contacts-2026-10-11/watchlist-bundle.json
```

次の工程で現在株価・流動性・財務・公開説明・決算日程を確認し、数カ月〜1年で検証する仮説と反証条件を作る。既に公開資料で答えられた質問を取り除き、どの回答がどのモデル入力を変えるか決めてからIR質問候補を保存する。
