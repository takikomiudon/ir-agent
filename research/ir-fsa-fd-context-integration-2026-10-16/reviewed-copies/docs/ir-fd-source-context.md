# IR返信の扱いを確認した金融庁資料の範囲

金融庁の[2018年2月6日と表示される発表ページ](https://www.fsa.go.jp/news/29/syouken/20180206.html)が現在リンクするガイドラインPDFを、2026年10月16日に取得した。[本文の限定レビューと原文](../research/ir-fsa-fd-literal-followup-2026-10-16/guideline-body-followup/README.md)、[親の照合記録](../research/ir-fsa-fd-literal-followup-2026-10-16/guideline-body-followup/parent-acceptance.json)を保持する。機械抽出は9頁、意味・画像の確認は物理5/7頁（印字3/5頁）である。

物理5頁の問2の答えは、未公表の確定的な情報で、公表されれば有価証券の価額に重要な影響を及ぼす蓋然性がある情報という説明をしている。未公表という一点だけで個別返信の区分を決めない。

物理7頁は、公表済み情報の詳細な内訳・補足説明などについて「一般的にはそれ自体では」という限定を置く。補足の中に、それ自体で重要な価格影響の蓋然性を持つ情報が含まれる場合の留保もある。契約済み為替予約と業績の関係の例を、その留保と一緒に保存した。戦略の議論やモザイク情報についても、本文の限定を落とさず読む。

本プロジェクトの`public_clarification` / `unclear` / `potential_nonpublic`は、既存契約による利用・保留の分類である。返信原文、公表根拠、対象期間と範囲を照合する。「補足説明」という題材や、会社から返事が来た事実だけで、自動的に利用可能へ対応付けない。今回の資料追加では分類器・判定gate・金融条件を変更していない。

対象者・取引関係者の範囲、具体的公表方法、他制度との関係は今回の確認範囲外である。発表HTMLの2018年制定・適用表示と、取得PDFの版履歴を分ける。HTTP Last-Modifiedの2022年2月28日を改定日へ読み替えず、2018年当時のPDFとの同一性、後年の改定や現行法全体も未確認として保持する。

最初の4GETで公式入口とリンクを確認し、そこで新たに得た直接リンクの別タスク1GETでPDFを取得した。他の本文や別hostの探索は続けていない。会社への質問・送信やDB登録は行っていない。
