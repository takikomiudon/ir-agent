# 年次入力と著者式の7社比較

既存の公表順で、実保存した年次連結EPS・同年度末BPSとmaxgfr/cribleのGraham Number式を対応させた。全14入力pathが原典・派生snapshotと一致し、現在の実DBと全object・native SHA・初保存・分類も照合した。対象年度・株式基準・詳細scopeは[JSON](summary.json)に保持する。

公開`reference-value`の価格なし出力を、rootの独立Fraction/Decimal100計算でも照合した。確率を補わず期待参考値null、価格・割安順位・金融採用・買値/利確価格の設定はない。年度が異なる会社間で株価水準や投資魅力を比較する表ではない。

7社14入力の充足はIRの追加価値を証明しない。既答を除き、会社に確認できる不明点がどの著者条件・入力を変え得るかを別途点検する。
