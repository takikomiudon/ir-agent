## 確認できた定義

出典は、岩井コスモ証券公式の[ネット取引・プラスネット閲覧レポート](https://www.iwaicosmo.co.jp/investment/net_report/)から公開されている[アナリスト銘柄情報サンプルPDF](https://www.iwaicosmo.co.jp/investment/net_report/pdf/sample_analyst.pdf)の**第3頁「投資判断の定義について」**。サンプルの日付は**2026-04-17**である。取得した2026-10-15時点の新規レポートや最新の全社規則とは扱わない。

| 条件 | 一次本文で確認した範囲 |
|---|---|
| 対象期間 | 「今後半年以内」。固定された6か月末の価格だけを指すとの定義は確認していない。 |
| 比較基準 | 「株価パフォーマンスがTOPIXを…上回る」。絶対株価の上昇余地の定義ではない。 |
| A | 「今後半年以内に株価パフォーマンスがTOPIXを15%程度以上上回ると予想」。 |
| B+ | 「今後半年以内に株価パフォーマンスがTOPIXを5〜15%程度上回ると予想」。 |
| B・B−・C | 行はあるが中央のSample透かしと重なるため、今回は全文・閾値を確定していない。記憶から補完していない。 |
| NR | ラベルを確認。投資判断の数値条件として使わない。 |
| 目標株価 | サンプル第1頁に掲載されている。一律の算定法、到達期限、到達時の全売却命令を定義した原文は今回確認していない。 |

PDFには本文テキスト層がなく、`pdftotext` では定義を抽出できなかった。第1・3頁を画像として読み、上記を**目視転記**した。HTML本文の文字列照合とは検証方法が異なる。原PDFと第3頁画像は `sources.json` 内にbase64で保存してある。引用の波形記号は視覚的な転記であり、元PDFに同じUnicode文字が存在するという意味ではない。

ここから自動判定の完全な区間はまだ作れない。「程度」という概数表現と境界の重複を、厳密な `>=15` や `5<=x<15` へ勝手に変換しない。TOPIXとの比較の演算方式、配当、税・手数料を含むかも未確認で、プロファイルの該当値は `null` にした。

## この定義を採用する場合に残る条件

岩井コスモのAを使うとしても、**絶対上昇余地15%以上という既存の買い条件へそのまま代入できない**。同じ期間のTOPIX見通しと比較方法が必要になる。レーティングはアナリストの投資評価の分類であり、個人のポジション量や損切り・利確手順を決める契約でもない。

採用候補を実運用へ進めるには、少なくとも次を別途埋める必要がある。

- どの版の定義を、どの市場・銘柄・期間に採用するか。現行の適用範囲と採用記録。
- 比較指標の予想、リターンの演算方式、配当を含むか、概数・境界の取り扱い。
- 実際の売買手数料、税、スプレッド、流動性、スリッページ。一般ページの最大手数料を本人の約定費用として代入しない。
- 保有の有無、資金、銘柄配分、ポートフォリオの集中と許容損失。
- 仮説崩壊、期限切れ、目標到達、新情報による評価変更をどの順で処理するか。
- IR回答がどの入力を変え、相対評価や行動候補を変えるのか。その判断に必要な事前確率・返信尤度・調査費用。

これらの条件を、公開レーティング表が自動的に提供するとは扱わない。現在のプロファイルは**採用0件、自動判定に使用可能0件**。不明値を保留することと、資料から数値を確認できたことを両立させている。

## 取得の有限性と検証

調査対象は4組織、**異なる本文取得先は12 URL**で終了した。robots・リダイレクトに伴うGETは本文取得先数とは別である。岩井コスモのサンプルは初回HTTP200ながら取得器の3MiB制限に達したため、親担当の限定指示により同じ実URLだけを8MiB上限で1回取り直した。本文取得試行は計13回で、保存できたPDFは3,855,577 bytes。アクセス拒否の迂回や新規URLの追加探索ではない。

全リクエストは従来のproxy・CA・robots処理を継承した。口座開設、ログイン、有料登録、IR送信、発注は0件。取得不能や未確認箇所を、外部著者の推奨閾値として補っていない。3社分が未確認であるため、この結果だけで方針の優劣や投資成績を比較することはできない。
